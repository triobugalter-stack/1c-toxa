# 1C UZ PRO ACADEMY

GitHub uchun tayyor, build-siz (vanilla HTML/CSS/JS) interaktiv o'quv sayt.

## Nima bor?
- 1C: Бухгалтерия для Узбекистана, редакция 3.0 bo'yicha 12 modul va 40+ dars
- 1C laboratoriya: hujjat → o'tkazish → provodka → hisobot mantiqi
- Xarid, sotuv, bank/kassa, ombor, markirovka, ish haqi, OS/NMA, ishlab chiqarish, EDO, hisobotlar
- Soliq markazi: QQS, foyda, JShDS, ijtimoiy, aylanma, aksiz, mol-mulk, yer, suv, yer qa'ri
- O'quv rejimidagi soliq kalkulyatori
- Real case'lar: javoblar bosqichma-bosqich ochiladi
- Terminlar lug'ati
- Screenshot/mockup kartalari va har bir ekran uchun kod ko'rinishi
- Dark/light mode
- LocalStorage orqali progress saqlash
- Responsive desktop/tablet/mobile
- Tashqi framework/CDN talab qilmaydi

## Ishga tushirish
1. ZIPni oching.
2. `index.html`ni Chrome/Edge'da oching.
3. GitHub Pages uchun repositoryga barcha fayllarni yuklang.
4. Settings → Pages → Deploy from branch → main/root.

## Muhim metodik izoh
Bu sayt o'quv simulyatori. 1Cdagi aniq provodka, soliq bazasi, imtiyoz va muddatlar real korxonaning operatsiyasi, hisob siyosati va amaldagi qonunchilikka bog'liq. Saytda “tipik misol” bilan “tekshiruv” alohida ajratilgan.
